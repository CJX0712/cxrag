# 向量数据库

向量数据库专门用于存储和检索高维嵌入向量，是语义检索与 RAG 的基础设施。

它的核心操作是近似最近邻搜索（ANN），常用算法包括 IVF、HNSW、PQ 以及基于量化的压缩索引。

相比传统数据库按关键词精确匹配，向量数据库依据语义相似度返回结果，能理解同义与近义表达。

主流开源方案有 FAISS、Milvus、Qdrant、Weaviate，云服务则有 Pinecone 与 Vertex AI Matching Engine。

衡量向量数据库的关键指标是召回率、查询延迟与内存占用，三者往往需要权衡。

在 RAG 中，段落经嵌入模型转化为向量后写入向量库，查询时把问题向量化再做最近邻检索。

为保证一致性，很多系统会同时使用向量库的语义检索与传统关键词检索做混合召回。
