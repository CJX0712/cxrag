# 检索增强生成 RAG

检索增强生成（Retrieval-Augmented Generation，简称 RAG）是一种把外部知识检索与大语言模型生成相结合的架构。

RAG 的核心动机是解决大语言模型的知识截止与幻觉问题。模型在回答之前，先从知识库检索相关片段，再把片段作为上下文送入生成器。

典型的 RAG 流程包括：文档切分、向量化建库、查询时检索最相关片段、将片段拼入提示词、由大模型生成答案。

RAG 的优势在于答案可溯源、知识可热更新、无需重新训练模型即可接入私有数据。

在工程实践中，混合检索（稀疏 BM25 加稠密向量）通常比单一检索更稳定，能同时覆盖关键词匹配与语义匹配。

重排阶段可以进一步提升精度，常用交叉编码器或轻量学习排序模型对候选段落重新打分。

评测 RAG 系统通常关注检索指标（recall@k、MRR、nDCG）以及生成质量（ faithfulness、答案相关性）。
