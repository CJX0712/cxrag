# 模型量化

模型量化是用更低比特数值表示权重与激活，从而压缩体积、降低延迟、减少显存占用的技术。

最常见的做法是把 FP16 或 FP32 权重转换为 INT8 甚至 INT4，推理时再反量化或直接使用低比特计算。

量化能显著降低部署成本，使大模型可在消费级显卡甚至 CPU 上运行，是边缘部署的关键手段。

训练后量化（PTQ）无需重新训练，实施简单；量化感知训练（QAT）则在训练中模拟量化误差，精度更高。

GPTQ 与 AWQ 是面向大语言模型的主流权重量化算法，能在 4 比特下较好保持精度。

量化的代价是潜在精度损失，需要结合校准集与评测来选择合适的比特数与方案。

在 RAG 与本地推理场景，量化让端侧运行百亿参数模型成为可能，是普惠 AI 的重要技术。
