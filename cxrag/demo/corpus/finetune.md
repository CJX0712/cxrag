# 大模型微调方法

微调是把预训练大模型适配到特定任务或领域的关键步骤，目标是在保留通用能力的同时提升下游表现。

全参数微调更新模型全部权重，效果最好但算力成本最高，且容易灾难性遗忘已学知识。

参数高效微调（PEFT）只训练少量新增参数，代表性方法包括 LoRA、QLoRA、Adapter 与 Prompt Tuning。

LoRA 通过低秩分解在权重旁插入可训练旁路，推理时合并回原权重，显存占用大幅下降。

指令微调使用成对的指令与回答数据，让模型学会遵循人类意图；对齐阶段常配合 RLHF 或 DPO。

选择微调策略时需要权衡数据规模、算力预算与效果要求，小数据场景优先 PEFT。

持续微调还要注意防过拟合与防遗忘，常用回放、正则与学习率warmup等手段。
